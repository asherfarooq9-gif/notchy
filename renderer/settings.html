Claude Code Checking... This adds 6 small entries to Claude Code's settings file, so the notch can show when Claude is working, needs you, or is done. Your other settings and hooks stay as they are, and a backup of the file is saved first.
One routine per line: a name, a colon, then commands separated by semicolons. Type “run good morning” to start it. Only safe commands work here: no shutdown, restart, sleep, typing, lock or Wi-Fi off.
Things you can type
  • “open Chrome”, “open Notepad”, “open Settings”
  • “open WhatsApp”, “open YouTube”, “open Gmail”
  • “search for cute cats”
  • “volume up”, “volume down”, “mute”
  • “pause”, “play”, “next”, “previous”
  • “lock the screen”
  • “brightness up”, “brightness down”, “take a screenshot”, “battery”
  • “wifi off”, “bluetooth on”, “snap left”, “maximize”, “show desktop”
  • “open downloads”, “open documents”, “type hello there”
  • “sleep”, “restart”, “shut down”, “cancel shutdown”
  • “run good morning” (your own routines, above)
Edge light A thin line of light around the notch. “Music” takes its color from the album art.
Screen glow Soft light around the screen edges that follows the colors of what is playing. “Full-screen only” lights up for movies and games. Protected video (Netflix, Prime in a browser) may show as black, so the glow stays off there.
Try it Sends a test message to the notch.
Tools in the panel Tick the ones you want. Use the arrows to change the order.
Character This window changes right away so you can preview. Press Save to also change the panel, the notch (its icon, edge line and glow) and the tray icon. The edge light color follows the look, and you can still change it.

Want more characters? Drop a pack file (.json) in the packs folder, then reopen this window.

All changes are saved.
